# 修复记录：保存所有标签状态（包括未检测到的）

## 需求变更

### 之前的逻辑

只保存 Gemini 检测到的标签（detected=true）：

```javascript
for (const result of analysisResults) {
  if (result.detected) {  // ❌ 只保存检测到的
    tagsToInsert.push({
      video_id: videoId,
      tag_name: result.tag,
      confidence: 1.0
    });
  }
}
```

**问题**：
- 无法知道哪些标签被检查过但未检测到
- 无法区分"未检查"和"检查了但不匹配"
- 不利于后续的数据分析和对比

### 新的逻辑

保存所有标签的检测结果（detected 和 not detected）：

```javascript
for (const result of analysisResults) {
  // ✅ 保存所有标签，用 confidence 区分
  tagsToInsert.push({
    video_id: videoId,
    tag_name: result.tag,
    confidence: result.detected ? 1.0 : 0.0  // 检测到=1.0, 未检测到=0.0
  });
}
```

**优势**：
- ✅ 完整记录所有标签的检测状态
- ✅ 可以看到哪些标签被明确排除
- ✅ 便于统计分析（如标签覆盖率）
- ✅ 支持未来的置信度优化

## 实现细节

### 1. 后端修改

**文件**: `backend/src/services/videoTagger.js`

**方法**: `saveTagResults()`

**修改前**:
```javascript
async saveTagResults(videoId, projectId, analysisResults, taxonomy) {
  const tagsToInsert = [];
  
  for (const result of analysisResults) {
    if (result.detected) {  // 只保存检测到的
      const category = taxonomy.find(cat => cat.tags.includes(result.tag));
      if (category) {
        tagsToInsert.push({
          video_id: videoId,
          project_id: projectId,
          tag_category_id: category.id,
          tag_name: result.tag,
          confidence: 1.0
        });
      }
    }
  }
  
  console.log(`💾 保存了 ${tagsToInsert.length} 个标签`);
}
```

**修改后**:
```javascript
async saveTagResults(videoId, projectId, analysisResults, taxonomy) {
  const tagsToInsert = [];
  
  for (const result of analysisResults) {
    // 保存所有标签，不再判断 detected
    const category = taxonomy.find(cat => cat.tags.includes(result.tag));
    if (category) {
      tagsToInsert.push({
        video_id: videoId,
        project_id: projectId,
        tag_category_id: category.id,
        tag_name: result.tag,
        confidence: result.detected ? 1.0 : 0.0  // 用 confidence 区分
      });
    }
  }
  
  const detectedCount = tagsToInsert.filter(t => t.confidence > 0).length;
  console.log(`💾 保存了 ${tagsToInsert.length} 个标签（其中 ${detectedCount} 个检测到）`);
}
```

## 数据分析优势

### 1. 标签覆盖率统计

```sql
-- 查看每个标签在所有视频中的检测率
SELECT 
  tag_name,
  COUNT(*) as total_videos,
  SUM(CASE WHEN confidence > 0 THEN 1 ELSE 0 END) as detected_count,
  ROUND(SUM(CASE WHEN confidence > 0 THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) as detection_rate
FROM video_tags
WHERE project_id = 2
GROUP BY tag_name
ORDER BY detection_rate DESC;
```

**结果示例**:
```
| tag_name        | total_videos | detected_count | detection_rate |
|-----------------|--------------|----------------|----------------|
| 素人体验故事    | 27           | 18             | 66.67%         |
| 面部特写        | 27           | 15             | 55.56%         |
| 淡纹抚皱        | 27           | 12             | 44.44%         |
| 开箱测评        | 27           | 2              | 7.41%          |
```

### 2. 视频相似度分析

```sql
-- 找出标签最相似的视频
SELECT 
  v1.video_id as video_1,
  v2.video_id as video_2,
  COUNT(*) as matching_tags
FROM video_tags v1
JOIN video_tags v2 ON v1.tag_name = v2.tag_name 
  AND v1.confidence > 0 
  AND v2.confidence > 0
  AND v1.video_id < v2.video_id
WHERE v1.project_id = 2
GROUP BY v1.video_id, v2.video_id
ORDER BY matching_tags DESC
LIMIT 10;
```

### 3. 标签组合分析

```sql
-- 查看哪些标签经常一起出现
SELECT 
  t1.tag_name as tag_1,
  t2.tag_name as tag_2,
  COUNT(*) as co_occurrence
FROM video_tags t1
JOIN video_tags t2 ON t1.video_id = t2.video_id 
  AND t1.tag_name < t2.tag_name
  AND t1.confidence > 0 
  AND t2.confidence > 0
WHERE t1.project_id = 2
GROUP BY t1.tag_name, t2.tag_name
ORDER BY co_occurrence DESC
LIMIT 10;
```

## 性能影响

### 数据量变化

**之前**:
- 每个视频约 6-10 条记录（只保存检测到的）
- 27 个视频 × 8 个标签 = 216 条记录

- 每个视频约 60 条记录（所有标签）

**选项 2**: 数据迁移
```sql
-- 为旧视频补充未检测到的标签
INSERT INTO video_tags (video_id, project_id, tag_category_id, tag_name, confidence)
SELECT 
  v.id as video_id,
  v.project_id,
  tc.id as tag_category_id,
  t.name as tag_name,
  0.0 as confidence
FROM videos v
CROSS JOIN tags t
JOIN tag_categories tc ON t.category_id = tc.id
WHERE NOT EXISTS (
  SELECT 1 FROM video_tags vt 
  WHERE vt.video_id = v.id 
  AND vt.tag_name = t.name
)
AND v.ai_tagging_status = 'completed';
```
