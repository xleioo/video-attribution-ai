# 修复记录：视频卡片只显示检测到的标签

## 问题描述
用户反馈：视频卡片显示的标签数量统计错误。

### 问题表现
视频卡片显示：
```
Vlog日常  开箱测评  开箱测评  +48
```

**问题：**
- "+48" 表示有 48 个剩余标签（总共 51 个标签）
- 但实际上只有 28 个标签被检测到（confidence > 0）
- 卡片应该只显示检测到的标签，而不是所有标签

### 期望行为
- 只显示检测到的标签（confidence > 0）
- 数量统计应该是：检测到的标签数量 - 已显示的 3 个
- 正确显示应该是：`Vlog日常  开箱测评  素人真实  +25`

## 根本原因

### Bug 位置
文件：`pages/ProjectDetail.tsx`  
行号：417-429

```tsx
<div className="flex flex-wrap gap-1">
  {videoTags[video.id]?.tags?.slice(0, 3).map((tag: any, index: number) => (
    <span className="text-[10px] bg-emerald-50 text-emerald-700 px-2 py-0.5 rounded">
      {tag.tag_name}
    </span>
  ))}
  {videoTags[video.id]?.tags?.length > 3 && (
    <span className="text-[10px] text-slate-400">
      +{videoTags[video.id].tags.length - 3}  {/* ❌ 使用了所有标签的数量 */}
    </span>
  )}
</div>
```

### 问题分析
代码直接使用 `videoTags[video.id]?.tags` 来显示标签，没有过滤掉 `confidence = 0` 的标签（未检测到的标签）。

由于数据库返回的 `tags` 数组包含所有 51 个标签（28 个检测到 + 23 个未检测到），前端会错误地显示所有标签的数量。

## 修复方案

### 修改代码
在渲染标签之前，先过滤出只有 `confidence > 0` 的标签：

```tsx
<div className="flex flex-wrap gap-1">
  {(() => {
    // 只显示检测到的标签 (confidence > 0)
    const detectedTags = videoTags[video.id]?.tags?.filter((t: any) => t.confidence > 0) || [];
    const displayTags = detectedTags.slice(0, 3);
    const remainingCount = detectedTags.length - 3;
    
    return (
      <>
        {displayTags.map((tag: any, index: number) => (
          <span
            key={tag.id || `${tag.tag_category_id}-${tag.tag_name}-${index}`}
            className="text-[10px] bg-emerald-50 text-emerald-700 px-2 py-0.5 rounded"
          >
            {tag.tag_name}
          </span>
        ))}
        {remainingCount > 0 && (
          <span className="text-[10px] text-slate-400">
            +{remainingCount}
          </span>
        )}
      </>
    );
  })()}
</div>
```

### 修复要点
1. ✅ 使用 `filter((t: any) => t.confidence > 0)` 过滤出检测到的标签
2. ✅ 基于过滤后的数组计算剩余数量
3. ✅ 只在剩余数量大于 0 时显示 "+数字"

## 修复效果

### 修复前
```
视频卡片显示：
Vlog日常  开箱测评  开箱测评  +48

数据说明：
- 显示前 3 个标签（可能包含未检测到的）
- +48 = 51（总标签数）- 3
```

### 修复后
```
视频卡片显示：
Vlog日常  开箱测评  素人真实  +25

数据说明：
- 只显示检测到的标签（confidence > 0）
- +25 = 28（检测到的标签数）- 3
```

### 数据验证
通过数据库查询验证：

```sql
SELECT 
  CASE 
    WHEN confidence > 0 THEN '检测到' 
    ELSE '未检测到' 
  END as status,
  COUNT(*) as count
FROM video_tags
WHERE video_id = 'vid_3_1'
GROUP BY status;
```

**结果：**
- 检测到：28 个
- 未检测到：23 个

**前端显示逻辑：**
- 卡片上显示前 3 个检测到的标签
- 剩余 25 个检测到的标签显示为 "+25"

## 其他展示区域

### 视频详情模态框
视频详情模态框中的标签展示**无需修改**，因为：
- 它需要显示**所有标签**（包括检测到和未检测到的）
- 通过图标和颜色区分：
  - ✓ 绿色：检测到（confidence > 0）
  - ✗ 灰色：未检测到（confidence = 0）

这个设计是正确的，用户可以在详情中看到完整的分析结果。

## 优化建议
如果后端返回的标签数组已经很大（例如 100+ 个标签），可以考虑：
1. 后端 API 增加参数：`?detected_only=true`
2. 后端只返回检测到的标签，减少网络传输
3. 前端无需过滤，直接显示
