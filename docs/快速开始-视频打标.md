# 快速开始：视频打标功能

## 5分钟快速配置

### 第1步：获取 API Key（2分钟）

1. 打开 https://aistudio.google.com/app/apikey
2. 登录 Google 账号
3. 点击"Create API Key"
4. 复制 Key（以 AIza 开头）

### 第2步：配置系统（1分钟）

1. 打开项目 → **设置页面**
2. 找到"AI 模型配置"
3. 粘贴 API Key
4. 点击**"测试"**按钮 → 看到"✓ API Key 有效！"
5. 点击右上角**"保存配置"**

### 第3步：开始打标（2分钟）

1. 进入**项目详情页**
2. 找到已下载的视频
3. 点击**"🏷️ 视频打标"**
4. 等待10-30秒
5. 查看识别的标签

## 常见问题速查

### Q: 点击打标提示"未配置 API Key"？
**A**: 去设置页面配置并保存 API Key

### Q: 测试显示"无效"？
**A**: 检查：
- Key 格式是否正确（AIza开头）
- 是否能访问 Google 服务
- Key 是否过期

### Q: 打标一直"处理中"？
**A**: 
- 查看后端日志：`tail -f backend.log`
- 检查网络连接
- 确认 API 配额未用完

### Q: 标签结果为空？
**A**:
- 可能视频内容与标签库不匹配
- 检查标签分类是否已初始化

## 一键命令

```bash
# 查看后端日志
tail -f backend.log

# 重启后端服务
cd backend && npm start

# 初始化标签数据
cd backend && node src/scripts/initTags.js
```
