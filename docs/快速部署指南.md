# 项目创建模块 - 快速部署指南

## 🚀 5分钟快速启动

### 步骤 1: 更新数据库

```bash
cd backend
npm run update-db
```

这将创建以下新表：
- ✅ videos（视频资产表）
- ✅ video_metrics（视频指标表）
- ✅ video_tags（视频标签表）
- ✅ download_queue（下载队列表）

### 步骤 2: 安装依赖

```bash
# 后端依赖
cd backend
npm install  # 会安装 axios, fs-extra

# 前端依赖
cd ..
npm install  # 会安装 xlsx
```

### 步骤 3: 启动服务

```bash
# 方式1: 使用启动脚本（推荐）
./start.sh

# 方式2: 手动启动
# 终端1 - 后端
cd backend && npm run dev

# 终端2 - 前端
npm run dev
```

### 步骤 4: 访问应用

打开浏览器访问：http://localhost:3000

点击侧边栏"项目管理"即可开始使用！

## 🔧 故障排查

### 问题1: 数据库更新失败

```bash
# 检查数据库连接
mysql -u root -p
use short_video_attribution;
show tables;

# 如果缺少表，手动运行更新脚本
cd backend
npm run update-db
```

### 问题2: 视频下载失败

检查后端日志：
```bash
# 查看下载服务日志
tail -f backend.log
```

常见原因：
- 视频URL无效
- 网络连接问题
- 文件权限问题

解决方案：
```bash
# 确保storage目录可写
mkdir -p backend/storage
chmod 755 backend/storage
```

### 问题3: 前端报错

```bash
# 清理并重新安装依赖
rm -rf node_modules package-lock.json
npm install

# 重启开发服务器
npm run dev
```

### 问题4: 静态文件访问403

```bash
# 检查storage目录权限
chmod -R 755 backend/storage
```

3. **下载重试**：暂未实现自动重试，失败的视频需要手动处理
