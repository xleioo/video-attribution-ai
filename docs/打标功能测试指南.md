# 视频打标功能测试指南

## 问题修复

### 已修复的问题

✅ **404 错误**: "未找到活跃的API配置"
- **原因**: App.tsx 尝试加载全局 API 配置，但数据库中没有
- **解决**: 修改为可选加载，404 不再显示为错误
- **文件**: `App.tsx`, `services/apiService.ts`

✅ **标签数据初始化**
- 确认数据库中已有 10 个标签分类
- 所有标签已正确导入

## 测试步骤

### 1. 准备工作

确保后端服务正在运行：
```bash
cd backend
npm start
```

确保前端服务正在运行：
```bash
npm run dev
```

### 2. 获取 Gemini API Key

1. 访问 https://aistudio.google.com/app/apikey
2. 登录 Google 账号
3. 创建或复制 API Key（格式：AIza...）

### 3. 测试打标功能

#### 步骤 A: 准备测试视频
1. 打开项目列表
2. 选择一个项目（或创建新项目）
3. 确保至少有一个视频已下载完成（状态显示"可播放"）

#### 步骤 B: 开始打标
1. 找到已下载的视频卡片
2. 点击"🏷️ 视频打标"按钮
3. 在弹出的模态框中输入 Gemini API Key
4. 点击"开始打标"

#### 步骤 C: 观察进度
1. 视频卡片应显示"AI打标中..."
2. 打开浏览器开发者工具（F12）→ Console
3. 应该没有红色错误信息
4. 等待 10-30 秒（取决于视频长度）

#### 步骤 D: 查看结果
1. 打标完成后，卡片显示"✓ 已打标"
2. 显示前 3 个检测到的标签
3. 点击视频卡片播放视频
4. 在播放模态框中查看所有标签

### 4. 验证功能

#### ✅ 应该看到：
- 没有 404 错误
- 没有"未找到活跃的API配置"错误
- 打标状态正确更新
- 标签正确显示

#### ❌ 不应该看到：
- 红色错误日志
- API 请求失败
- 页面崩溃
- 标签为空

## 故障排除

### 问题 1: 仍然看到 404 错误

**解决方案**:
```bash
# 清除浏览器缓存
Ctrl+Shift+Delete (或 Cmd+Shift+Delete)

# 或者硬刷新
Ctrl+Shift+R (或 Cmd+Shift+R)
```

### 问题 2: 打标一直处理中

**可能原因**:
- API Key 无效
- 网络问题
- Gemini API 配额用完

**解决方案**:
```bash
# 查看后端日志
cd backend
tail -f ../backend.log

# 检查错误信息
```

### 问题 3: 标签显示为空

**可能原因**:
- 视频内容无法识别
- 标签数据未初始化

**解决方案**:
```bash
# 重新初始化标签
cd backend
node src/scripts/initTags.js
```

### 问题 4: "标签分类不存在"

**解决方案**:
```bash
# 检查数据库
mysql -u root -p short_video_attribution

# 查询标签分类
SELECT COUNT(*) FROM tag_categories;

# 如果为 0，运行初始化脚本
node backend/src/scripts/initTags.js
```

## 性能预期

- **单个视频打标时间**: 10-30 秒
- **API 调用次数**: 每个视频 1 次
- **内存占用**: 视频大小的 2-3 倍（base64 编码）
- **并发限制**: 一次 1 个（避免 API 限流）

## 注意事项

1. **API 配额**: Gemini API 有免费配额限制
2. **视频大小**: 建议不超过 50MB
3. **网络要求**: 需要访问 Google API
4. **时间成本**: 长视频需要更长分析时间
