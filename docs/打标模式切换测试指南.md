# 打标模式切换功能测试指南

## 测试目标

验证系统能够正确切换和应用不同的视频打标模式。

## 测试前准备

1. 确保后端服务正在运行（端口 3001）
2. 确保前端应用正在运行（端口 3000）
3. 确保数据库中有测试项目和视频
4. 确保已配置有效的 Gemini API Key

## 测试步骤

### 测试 1: 查看默认模式

**步骤**：
1. 打开浏览器，访问 `http://localhost:3000`
2. 点击左侧菜单的"系统设置"
3. 查看"AI 模型配置"区域

**预期结果**：
- ✅ 显示"视频打标模式"选项
- ✅ "方式1: 对比打标"默认被选中
- ✅ "方式2: 主动挖掘"显示"即将推出"标签并处于禁用状态
- ✅ 显示蓝色提示框："💡 提示：当前模式下，只有在下方"内容标签体系配置"中定义的标签才会被识别。"

### 测试 2: 切换到主动挖掘模式（UI 测试）

**步骤**：
1. 在设置页面尝试点击"方式2: 主动挖掘"

**预期结果**：
- ✅ 由于该选项被禁用，无法选中
- ✅ 选项显示为灰色/半透明状态

### 测试 3: 保存对比打标模式

**步骤**：
1. 确保"方式1: 对比打标"被选中
2. 点击右上角"保存配置"按钮
3. 等待保存成功提示

**预期结果**：
- ✅ 显示"配置保存成功！"提示
- ✅ 刷新页面后，"对比打标"仍然被选中

### 测试 4: 对比模式下执行视频打标

**步骤**：
1. 进入"项目管理"页面
2. 选择一个已下载完视频的项目
3. 找到一个状态为"ready"的视频
4. 点击视频卡片上的"🏷️ 视频打标"按钮
5. 确认打标操作

**预期结果**：
- ✅ 显示"视频已加入打标队列！"提示
- ✅ 视频卡片显示打标进度
- ✅ 打标完成后显示检测到的标签（带 ✓ 标记）

### 测试 5: 验证后端模式检查（开发者测试）

**步骤**：
1. 打开浏览器开发者工具（F12）
2. 切换到 Console 标签
3. 在设置页面，打开浏览器控制台
4. 执行以下代码手动修改模式为 'discovery'：
```javascript
fetch('http://localhost:3001/api/config/1', {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    config_name: 'Gemini API',
    api_key: 'YOUR_API_KEY',
    provider: 'gemini',
    is_active: true,
    tagging_mode: 'discovery'
  })
})
```
5. 尝试对视频进行打标

**预期结果**：
- ✅ 后端返回 400 错误
- ✅ 错误消息："当前打标模式为"主动挖掘"，暂不支持。请在设置中切换为"对比打标"模式。"
- ✅ 视频不会进入打标队列

### 测试 6: 数据库验证（可选）

**步骤**：
1. 连接到 MySQL 数据库
2. 执行查询：
```sql
SELECT id, config_name, tagging_mode FROM api_configs WHERE is_active = 1;
```

**预期结果**：
- ✅ `tagging_mode` 字段存在
- ✅ 值为 'comparison' 或 'discovery'
- ✅ 默认值为 'comparison'

## 测试场景矩阵

| 模式 | 打标按钮 | 后端响应 | 结果 |
|------|---------|---------|------|
| comparison | 可点击 | 200 OK | ✅ 正常打标 |
| discovery | 可点击 | 400 Error | ✅ 提示切换模式 |

## 常见问题排查

### 问题 1: 设置页面不显示打标模式选项

**可能原因**：
- 前端代码未更新
- 浏览器缓存

**解决方法**：
1. 清除浏览器缓存（Ctrl+Shift+R 或 Cmd+Shift+R）
2. 检查前端控制台是否有错误
3. 确认 Settings.tsx 文件已更新

### 问题 2: 保存后模式没有生效

**可能原因**：
- 数据库字段未添加
- 后端服务未重启

**解决方法**：
1. 运行数据库更新脚本：
```bash
cd backend
node src/scripts/updateDatabase.js
```
2. 重启后端服务：
```bash
pkill -f "node.*server.js"
cd backend
node src/server.js
```

### 问题 3: 选择主动挖掘模式后无法打标

**说明**：
这是预期行为！"主动挖掘"模式尚未实现，目前被禁用。
