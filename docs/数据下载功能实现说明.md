# 数据下载功能实现说明

## 功能概述
当项目中的所有视频都完成打标后，用户可以通过点击"下载项目数据"按钮，下载包含所有视频数据的 CSV 格式宽表。

## 功能要求

### 1. 触发条件
- ✅ 项目中的所有视频都必须已完成打标（`status = 'ready'` 且 `ai_tagging_status = 'completed'`）
- ✅ 如果还有视频未完成打标，按钮不显示，或点击时提示错误

### 2. 数据格式要求

#### CSV 文件结构
宽表包含以下字段：

1. **基础字段**
   - `视频标题`：视频的标题（如果为空则使用视频ID）
   - `视频URL`：视频的原始URL

2. **业务指标字段**
   - 创建项目时用户指定的所有分析指标
   - 字段名：使用用户在 Excel 中定义的列名

3. **标签字段**
   - 所有标签体系中的标签（无论是否检测到）
   - 字段命名规则：`标签类别名：标签名`
   - 例如：`内容形式：Vlog日常`、`场景视觉：家居梳妆`

#### 数据值规则

1. **指标字段**
   - 如果视频有该指标值，显示实际数值
   - 如果视频没有该指标值，显示空字符串

2. **标签字段（One-Hot 编码）**
   - 如果视频检测到该标签（`confidence > 0`）：值为 `1`
   - 如果视频未检测到该标签（`confidence = 0`）：值为 `0`
   - **重要**：每条记录必须包含所有标签列，即使值为 0

### 3. 文件命名规则
格式：`日期-项目名字-视频数量.csv`

示例：
- `20260119-项目A-25.csv`
- `20260119-双11视频分析-100.csv`

日期格式：`YYYYMMDD`（年月日，无分隔符）

## 技术实现

### 后端实现

#### 1. 路由配置
文件：`backend/src/routes/projectRoutes.js`

```javascript
router.get('/:id/download', projectController.downloadProjectData);
```

#### 2. 控制器方法
文件：`backend/src/controllers/projectController.js`

**方法名**：`downloadProjectData`

**实现逻辑**：
1. 验证项目是否存在
2. 获取项目所有视频
3. 检查是否所有视频都已完成打标
4. 获取所有标签分类和标签
5. 构建 CSV 表头（视频标题、视频URL、指标字段、所有标签字段）
6. 遍历每个视频，构建数据行：
   - 获取视频的指标数据
   - 获取视频的标签数据
   - 构建 one-hot 编码的标签值
7. 生成 CSV 内容
8. 设置响应头（Content-Type、Content-Disposition）
9. 添加 BOM（支持 Excel 正确显示中文）
10. 返回 CSV 文件

**关键代码片段**：
```javascript
// 检查是否所有视频都已完成打标
const allTagged = videos.every(v => 
  v.status === 'ready' && v.ai_tagging_status === 'completed'
);

// 构建所有标签列表（格式：标签类别名：标签名）
const allTags = [];
tagCategories.forEach(cat => {
  cat.tags.forEach(tagName => {
    allTags.push({
      categoryName: cat.name,
      tagName: tagName,
      columnName: `${cat.name}：${tagName}`
    });
  });
});

// 构建标签的 one-hot 编码
videoTags.forEach(t => {
  const key = `${t.category_name}：${t.tag_name}`;
  tagsMap[key] = t.confidence > 0 ? 1 : 0;
});

// 确保所有标签列都存在（即使值为 0）
...allTags.map(t => tagsMap[t.columnName] || 0)
```

#### 3. CSV 生成
- 使用标准 CSV 格式（逗号分隔，双引号包裹）
- 处理特殊字符（双引号转义为两个双引号）
- 添加 UTF-8 BOM（`\ufeff`）以支持 Excel 正确显示中文

## 错误处理

### 后端错误
1. **项目不存在**：返回 404
2. **视频未全部完成打标**：返回 400，提示"项目中的视频尚未全部完成打标，无法下载数据"
3. **服务器错误**：返回 500，记录错误日志

### 前端错误
1. **下载失败**：显示错误提示
2. **网络错误**：显示网络错误信息
3. **文件生成失败**：显示服务器错误信息
