# 数据库结构优化：打标状态字段

## 问题发现
在实现智能轮询时，发现 `videos` 表的 `ai_tagging_status` 字段存在语义问题：

### 之前的设计
```sql
ai_tagging_status ENUM('pending','processing','completed','error') DEFAULT 'pending'
```

**问题：**
- 所有下载完成的视频自动被标记为 `'pending'`
- 这造成语义混淆：`'pending'` 通常表示"任务已在队列中"，但实际上用户可能根本没点击打标按钮
- 无法区分"从未发起打标"和"已加入队列等待处理"两种状态

### 正确的业务逻辑
```
NULL (未发起打标请求)
    ↓ [用户点击打标按钮]
processing (正在打标)
    ↓ [完成]
completed (已完成) 或 error (失败)
```

## 修复方案

### 1. 数据库字段定义
将 `ai_tagging_status` 字段修改为：
```sql
ai_tagging_status ENUM('processing','completed','error') DEFAULT NULL 
COMMENT 'AI标签分析状态：NULL=未开始，processing=处理中，completed=已完成，error=失败'
```

**关键变化：**
- ✅ 移除了 `'pending'` 状态
- ✅ 默认值改为 `NULL`
- ✅ 允许该字段为 `NULL`

### 2. 数据迁移
执行脚本 `backend/src/scripts/fixTaggingStatus.js` 完成：
- 将所有 `'pending'` 状态且没有标签数据的视频改为 `NULL`（28 个视频）
- 保留已完成打标的视频状态为 `'completed'`（2 个视频）
- 修改字段定义

### 3. 更新数据库初始化脚本
修改 `backend/src/scripts/updateDatabase.js`，确保未来创建的表结构是正确的。

## 业务流程

### 视频打标完整流程
1. **初始状态**：视频下载完成后，`ai_tagging_status = NULL`
   - 前端显示："🏷️ 视频打标" 按钮
   - 不轮询该视频

2. **用户发起打标**：点击"视频打标"按钮
   - 调用 `POST /api/videos/:id/tag` 接口
   - 后端创建打标任务，状态变为 `'processing'`
   - 前端检测到 `processing` 状态，启动智能轮询

3. **打标进行中**：`ai_tagging_status = 'processing'`
   - 前端显示：旋转图标 + "AI打标中..." + 进度条
   - 每 2 秒轮询一次视频列表和标签接口
   - 后端异步处理，更新进度（0-100%）

4. **打标完成**：`ai_tagging_status = 'completed'`
   - 前端显示："✓ 已打标" + 标签预览 + "重新打标" 按钮
   - 停止轮询该视频
   - 用户点击卡片可查看完整标签结果

5. **打标失败**：`ai_tagging_status = 'error'`
   - 前端显示："打标失败" + "重试" 按钮
   - 停止轮询
   - 用户可点击重试

6. **重新打标**：点击"重新打标"按钮
   - 重新创建打标任务，状态变为 `'processing'`
   - 轮询重新启动
   - 删除旧标签数据，生成新标签

## 智能轮询逻辑

### 轮询触发条件
```typescript
const hasDownloadingVideos = videos.some(v => 
  v.status === 'downloading' || v.status === 'pending'
);
const hasTaggingVideos = videos.some(v => 
  v.ai_tagging_status === 'processing'
);

// 只有当有任务进行时，才启动轮询
if (!hasDownloadingVideos && !hasTaggingVideos) {
  return; // 不启动定时器
}
```

### 轮询内容
当检测到有任务进行时：
- **视频列表**：`GET /api/projects/:id/videos` - 更新所有视频状态
- **项目状态**：`GET /api/projects/:id/status` - 更新项目进度
- **标签详情**：`GET /api/videos/:id/tags` - 仅轮询 `processing` 状态的视频

### 轮询停止
当满足以下条件时，轮询自动停止：
- 没有 `downloading` 或 `pending` 状态的视频
- 没有 `processing` 状态的打标任务

## 数据库表结构

### videos 表（相关字段）
| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `status` | ENUM('pending','downloading','ready','error') | 'pending' | 视频下载状态 |
| `ai_tagging_status` | ENUM('processing','completed','error') | NULL | AI打标状态：NULL=未开始 |
| `ai_tagging_progress` | INT | 0 | 打标进度（0-100） |
| `ai_tagging_error` | TEXT | NULL | 打标错误信息 |

### video_tags 表
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT | 主键 |
| `video_id` | VARCHAR(100) | 视频ID |
| `project_id` | INT | 项目ID |
| `tag_category_id` | VARCHAR(100) | 标签分类ID |
| `tag_name` | VARCHAR(255) | 标签名称 |
| `confidence` | DECIMAL(5,4) | 置信度（0.0-1.0，检测到=1.0，未检测到=0.0） |
