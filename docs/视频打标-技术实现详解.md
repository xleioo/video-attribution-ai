# 视频打标 - 技术实现详解

## 概述

视频打标功能使用 Google Gemini 2.5 Flash 模型对视频内容进行智能分析，根据预定义的标签体系自动识别视频中的内容特征。

## 完整流程

```
用户点击打标
    ↓
添加到队列
    ↓
读取视频文件 (10%)
    ↓
获取标签体系 (30%)
    ↓
调用 Gemini API (50%)
    ├─ 上传视频 (base64)
    ├─ 发送 Prompt
    └─ 接收分析结果
    ↓
解析 JSON 响应
    ↓
保存标签到数据库 (80%)
    ↓
完成 (100%)
```

## Gemini API 调用详解

### 1. 调用位置

**文件**: `backend/src/services/videoTagger.js`

**方法**: `analyzeVideoWithGemini(apiKey, base64Video, mimeType, taxonomy)`

**调用时机**: 视频文件读取完成后，进度 50%

### 2. API 配置

```javascript
const { GoogleGenAI } = await import('@google/genai');
const ai = new GoogleGenAI({ apiKey });

const response = await ai.models.generateContent({
  model: "gemini-2.5-flash",  // 使用最新的 Flash 模型
  contents: {
    parts: [
      {
        inlineData: {
          mimeType: "video/mp4",
          data: base64Video,  // Base64 编码的视频
        },
      },
      {
        text: prompt,  // 分析指令
      },
    ],
  },
  config: {
    responseMimeType: "application/json",  // 强制返回 JSON
    temperature: 0.1,  // 低温度确保稳定性
  }
});
```

### 3. Prompt 构建

#### 完整 Prompt 结构

```
Role: You are a senior video content analyst for the beauty brand "Elixir" (怡丽丝尔).
Task: Strictly analyze the visual and audio content of the uploaded short video and determine which tags from the provided taxonomy are present.

[标签体系 - 动态生成]
1. Dimension: 内容形式标签
   Tags: [榜单推荐, Vlog日常, 教程/手法, 开箱测评, 直播剪辑]

2. Dimension: 主角人设标签
   Tags: [品牌官方, 学生少女, 宝妈人群, 专业人士, 素人真实]

... (共 10 个维度)

Instructions:
1. Review the video content frame by frame and listen to the audio.
2. For EACH Dimension listed above, check if any of its specific Tags apply to this video.
3. A tag should be marked as "detected" ONLY if there is clear visual or audio evidence.
4. Be strict. Do not invent tags. Only use tags listed in the taxonomy.

Output Format:
Return a JSON object with a single property "detected_tags". This property must be an array of strings containing EXACTLY the tag names that were found in the video.

Example Output:
{
  "detected_tags": ["素人体验故事", "淡纹抚皱", "面部特写/按摩演示", "亲子家庭"]
}
```

#### Prompt 关键要素

1. **角色定位**: 资深视频内容分析师
2. **品牌背景**: 怡丽丝尔美妆品牌
3. **任务明确**: 严格对照标签体系进行分类
4. **标签体系**: 动态从数据库加载，包含 10 个维度
5. **分析要求**: 
   - 逐帧审查视频
   - 听取音频内容
   - 只标记有明确证据的标签
   - 严格使用预定义标签
6. **输出格式**: JSON 格式，包含检测到的标签名称数组

#### 解析逻辑

```javascript
const text = response.text;  // 获取响应文本

// 清理可能的 markdown 代码块
let cleanText = text.trim();
if (cleanText.startsWith('```json')) {
  cleanText = cleanText.replace(/```json\n?/g, '').replace(/```\n?/g, '');
}

// 解析 JSON
const json = JSON.parse(cleanText);
const detectedTags = json.detected_tags;  // 提取检测到的标签

// 映射到完整标签列表
const results = allTags.map(tag => ({
  tag: tag,
  detected: detectedTags.includes(tag),  // true/false
}));
```

### 6. 结果保存

#### 保存逻辑

```javascript
async saveTagResults(videoId, projectId, analysisResults, taxonomy) {
  // 1. 删除旧标签
  await VideoModel.deleteVideoTags(videoId);
  
  // 2. 准备新标签数据
  const tagsToInsert = [];
  
  for (const result of analysisResults) {
    if (result.detected) {  // 只保存检测到的标签
      // 找到标签所属的分类
      const category = taxonomy.find(cat => cat.tags.includes(result.tag));
      
      if (category) {
        tagsToInsert.push({
          video_id: videoId,
          project_id: projectId,
          tag_category_id: category.id,
          tag_name: result.tag,
          confidence: 1.0  // Gemini 返回布尔值，这里统一为 1.0
        });
      }
    }
  }
  
  // 3. 批量插入
  if (tagsToInsert.length > 0) {
    await VideoModel.saveVideoTags(tagsToInsert);
    console.log(`💾 保存了 ${tagsToInsert.length} 个标签`);
  }
}
```

#### 数据库结构

**表**: `video_tags`

```sql
CREATE TABLE video_tags (
  id INT AUTO_INCREMENT PRIMARY KEY,
  video_id VARCHAR(100) NOT NULL,
  project_id INT NOT NULL,
  tag_category_id VARCHAR(50) NOT NULL,
  tag_name VARCHAR(100) NOT NULL,
  confidence FLOAT DEFAULT 1.0,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (video_id) REFERENCES videos(id),
  FOREIGN KEY (tag_category_id) REFERENCES tag_categories(id)
);
```

## 常见问题

### Q1: Gemini 返回的标签不准确？

**可能原因**:
- 视频内容与标签体系不匹配
- Prompt 不够明确
- 视频质量问题（模糊、无声等）

**解决方案**:
1. 优化 Prompt，增加更具体的指导
2. 调整标签体系，使其更贴合实际内容
3. 提高视频质量

### Q2: 某些标签从不被检测到？

**可能原因**:
- 标签定义不清晰
- 视频中确实没有该类内容
- Prompt 中该标签的描述不够突出

**解决方案**:
1. 检查标签定义是否明确
2. 在 Prompt 中添加该标签的详细说明
3. 提供示例视频进行测试

### Q3: 如何调整检测灵敏度？

**当前设置**:
```javascript
temperature: 0.1  // 低温度 = 更保守、更稳定
```

**调整建议**:
- `0.0 - 0.2`: 非常保守，只标记非常确定的标签
- `0.3 - 0.5`: 平衡，适合大多数场景
- `0.6 - 1.0`: 更激进，可能产生更多标签但准确性降低

## 性能优化

### 当前性能

- **单视频处理时间**: 10-30 秒
- **API 调用**: 1 次/视频
- **内存占用**: 视频大小 × 2-3（base64 编码）

### 优化建议

1. **视频压缩**: 上传前压缩视频，减少传输时间
2. **批量处理**: 一次 API 调用分析多个视频（如果 Gemini 支持）
3. **缓存结果**: 相同视频不重复分析
4. **异步队列**: 已实现，避免阻塞
