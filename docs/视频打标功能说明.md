# 视频打标功能说明

## 功能概述

视频打标功能允许用户使用 Google Gemini AI 对已下载的视频进行内容标签分析，自动识别视频中的各种内容特征。

## 技术架构

### 后端

1. **数据库扩展**
   - `videos` 表添加了 AI 打标状态字段：
     - `ai_tagging_status`: 打标状态（pending/processing/completed/error）
     - `ai_tagging_progress`: 打标进度（0-100）
     - `ai_tagging_error`: 错误信息

2. **打标队列服务** (`backend/src/services/videoTagger.js`)
   - 异步队列管理，避免并发请求过多
   - 自动读取视频文件并转换为 base64
   - 调用 Gemini API 进行视频内容分析
   - 将分析结果保存到数据库

3. **API 接口**
   - `POST /api/videos/:video_id/tag` - 开始视频打标
   - `GET /api/videos/:video_id/tags` - 获取视频标签
   - `GET /api/tagging-queue/status` - 获取打标队列状态

### 前端

1. **视频卡片增强**
   - 已下载视频显示"视频打标"按钮
   - 显示打标状态（处理中/已完成/失败）
   - 显示前3个检测到的标签

2. **API Key 输入**
   - 点击打标按钮弹出模态框
   - 输入 Gemini API Key
   - 提交后加入打标队列

3. **标签结果展示**
   - 视频卡片：显示前3个标签 + 总数
   - 视频播放模态框：显示所有检测到的标签
   - 标签按分类组织显示

## 使用流程

1. **准备工作**
   - 获取 Google Gemini API Key（访问 https://makersuite.google.com/app/apikey）
   - 确保视频已成功下载（状态为"ready"）

2. **开始打标**
   - 在项目详情页找到已下载的视频
   - 点击"🏷️ 视频打标"按钮
   - 输入 Gemini API Key
   - 点击"开始打标"

3. **等待分析**
   - 视频会加入打标队列
   - 显示"AI打标中..."状态
   - 系统会自动轮询更新状态（每5秒）

4. **查看结果**
   - 打标完成后，视频卡片显示"✓ 已打标"
   - 显示检测到的标签（前3个）
   - 点击视频播放，可查看所有标签

## 标签体系

系统使用预定义的内容标签体系（来自 `constants.ts`）：

- 内容形式标签
- 主角人设标签
- 场景画面标签
- 呈现手法标签
- 功效诉求标签
- 情绪语气标签
- 画面主体
- 内容策略
- 情绪语气
- 功效诉求与人群

## 技术细节

### Gemini API 调用

```javascript
// 使用 gemini-1.5-flash 模型
const model = genAI.getGenerativeModel({ model: "gemini-1.5-flash" });

// 发送视频和提示词
const result = await model.generateContent([
  {
    inlineData: {
      mimeType: 'video/mp4',
      data: base64Video,
    },
  },
  prompt,
]);
```

### 标签检测逻辑

1. 将视频转换为 base64 编码
2. 构建包含标签体系的提示词
3. Gemini 分析视频内容
4. 返回检测到的标签列表
5. 映射到完整标签体系（True/False）
6. 保存到 `video_tags` 表

### 队列管理

- 单线程处理（concurrentTagging = 1）
- 避免 Gemini API 限流
- 每个视频处理后延迟 2 秒
- 自动重试失败的任务

## 注意事项

1. **API Key 安全**
   - API Key 仅用于当前请求
   - 不会保存到服务器
   - 建议使用环境变量管理

2. **视频大小限制**
   - Gemini API 对视频大小有限制
   - 建议视频不超过 50MB
   - 过大的视频可能导致超时

3. **成本控制**
   - 每次打标会消耗 Gemini API 配额
   - 建议批量处理前评估成本
   - 可以重新打标但会重新计费

4. **处理时间**
   - 每个视频分析约需 10-30 秒
   - 取决于视频长度和复杂度
   - 队列中的视频会依次处理

## 故障排除

### 打标失败

1. 检查 API Key 是否正确
2. 确认视频文件存在且完整
3. 查看错误信息（鼠标悬停在失败状态上）
4. 尝试重新打标

### 标签不准确

1. 视频内容可能不清晰
2. 标签体系可能需要调整
3. 可以重新打标获取新结果

### 队列卡住

1. 检查后端日志
2. 重启后端服务
3. 清理打标队列
