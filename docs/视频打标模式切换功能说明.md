# 视频打标模式切换功能说明

## 功能概述

系统现在支持两种视频打标模式，用户可以在设置页面中自由切换：

### 方式1: 对比打标（已实现）
- **描述**：根据"内容标签体系配置"中已定义的标签对视频进行逐一比对
- **工作原理**：AI 模型会检查视频内容是否包含预定义的每个标签
- **适用场景**：
  - 已有明确的标签体系
  - 需要标准化的分类结果
  - 希望控制标签的范围和数量
- **状态**：✅ 已实现并可用

### 方式2: 主动挖掘（即将推出）
- **描述**：AI 主动分析视频内容，挖掘并提取视频中的关键特征和元素
- **工作原理**：不限于预定义标签，AI 会自由发现视频中的特点
- **适用场景**：
  - 探索性分析
  - 发现新的内容特征
  - 不确定应该定义哪些标签
- **状态**：🚧 开发中

## 使用方法

### 1. 配置打标模式

1. 进入"系统设置"页面
2. 在"AI 模型配置"区域找到"视频打标模式"选项
3. 选择所需的打标模式：
   - **对比打标**：使用预定义标签进行识别
   - **主动挖掘**：AI 自由发现内容特征（暂未开放）
4. 点击"保存配置"按钮

### 2. 执行视频打标

- **对比打标模式**：
  1. 确保在"内容标签体系配置"中已定义标签
  2. 在项目详情页面，点击视频卡片上的"🏷️ 视频打标"按钮
  3. 系统会根据标签体系对视频进行分析
  4. 结果显示为每个标签的匹配状态（✓ 或 ✗）

- **主动挖掘模式**：
  - 暂未开放，选择此模式时点击打标按钮会提示切换回对比模式

## 技术实现

### 数据库变更

在 `api_configs` 表中新增字段：
```sql
tagging_mode ENUM('comparison', 'discovery') DEFAULT 'comparison'
```

### 后端逻辑

**文件**：`backend/src/controllers/videoController.js`

在 `startVideoTagging` 方法中添加了模式检查：
```javascript
// 检查打标模式
const taggingMode = apiConfig.tagging_mode || 'comparison';

if (taggingMode !== 'comparison') {
  return res.status(400).json({
    success: false,
    message: '当前打标模式为"主动挖掘"，暂不支持。请在设置中切换为"对比打标"模式。'
  });
}
```

### 前端实现

**文件**：`pages/Settings.tsx`

1. 添加了 `taggingMode` 状态管理
2. 在页面加载时从数据库读取当前配置
3. 提供单选按钮供用户切换模式
4. 保存时将选择的模式同步到数据库

**UI 特点**：
- 清晰的模式说明
- "主动挖掘"模式显示"即将推出"标签并禁用
- 对比模式下显示提示信息

## 业务逻辑

### 模式验证流程

```
用户点击"视频打标" 
  ↓
后端检查 API 配置
  ↓
验证 tagging_mode 字段
  ↓
如果是 'comparison' → 执行现有打标逻辑
  ↓
如果是 'discovery' → 返回错误提示
```

### 默认行为

- 新安装的系统默认为"对比打标"模式
- 未配置 `tagging_mode` 时，系统自动使用"对比打标"

## 注意事项

1. **模式切换**：切换模式不会影响已打标的视频结果
2. **标签体系**：对比模式依赖于"内容标签体系配置"，请确保已定义标签
3. **API Key**：两种模式都需要配置有效的 Gemini API Key
4. **向后兼容**：未配置模式的旧数据会自动使用"对比打标"模式
