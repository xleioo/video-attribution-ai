# 视频打标流程说明

## 功能概述

视频打标功能采用后台异步队列机制，确保打标过程稳定可靠，不受前端页面刷新或关闭的影响。前端通过轮询机制实时更新打标进度。

## 工作流程

### 后端：异步队列处理

```
用户点击打标
    ↓
添加到打标队列
    ↓
后台异步处理
    ├─ 10%: 准备视频文件
    ├─ 30%: 获取标签体系
    ├─ 50%: 调用 Gemini API
    ├─ 80%: 保存标签结果
    └─ 100%: 打标完成
```

### 前端：实时状态轮询

```
每 2 秒轮询一次
    ↓
获取打标状态和进度
    ↓
更新 UI 显示
    ├─ processing: 显示进度条
    ├─ completed: 显示标签
    └─ error: 显示错误信息
```

## 技术实现

### 1. 后端队列服务

**文件**: `backend/src/services/videoTagger.js`

#### 核心特性

- ✅ **异步队列**: 使用内存队列管理打标任务
- ✅ **顺序处理**: 一次处理一个视频，避免 API 限流
- ✅ **进程持久**: 后台运行，不受前端影响
- ✅ **实时进度**: 多阶段进度更新 (10% → 30% → 50% → 80% → 100%)
- ✅ **错误处理**: 失败后自动标记，支持重试

#### 队列方法

```javascript
class VideoTaggerService {
  // 添加到队列
  async addToQueue(videoId, projectId, apiKey)
  
  // 处理队列
  async processQueue()
  
  // 打标单个视频
  async tagVideo(task)
  
  // 调用 Gemini API
  async analyzeVideoWithGemini(apiKey, video, mimeType, taxonomy)
  
  // 保存结果
  async saveTagResults(videoId, projectId, results, taxonomy)
}
```

### 2. 数据库字段

**表**: `videos`

| 字段 | 类型 | 说明 |
|------|------|------|
| ai_tagging_status | ENUM | 打标状态：pending, processing, completed, error |
| ai_tagging_progress | INT | 打标进度：0-100 |
| ai_tagging_error | TEXT | 错误信息 |

**表**: `video_tags`

| 字段 | 类型 | 说明 |
|------|------|------|
| video_id | VARCHAR | 视频 ID |
| project_id | INT | 项目 ID |
| tag_category_id | VARCHAR | 标签分类 ID |
| tag_name | VARCHAR | 标签名称 |
| confidence | FLOAT | 置信度 (0.0 或 1.0) |

### 3. 前端轮询机制

**文件**: `pages/ProjectDetail.tsx`

#### 轮询配置

```javascript
// 每 2 秒轮询一次
useEffect(() => {
  const interval = setInterval(() => {
    loadVideos();        // 更新视频列表
    loadProjectStatus(); // 更新项目状态
    loadVideoTags();     // 更新标签数据
  }, 2000);

  return () => clearInterval(interval);
}, [projectId, videos]);
```

#### 开始打标

```http
POST /api/videos/:video_id/tag
```

## 性能优化

### 1. 轮询优化

- **间隔**: 2秒（平衡实时性和服务器负载）
- **条件轮询**: 只轮询状态为 'processing' 的视频
- **智能停止**: 所有视频打标完成后停止轮询

### 2. 队列优化

- **顺序处理**: 避免并发导致的 API 限流
- **延迟控制**: 每个任务之间间隔 2 秒
- **内存管理**: 及时清理已完成的任务

### 3. 前端优化

- **防抖处理**: 避免重复点击
- **缓存标签**: 已加载的标签缓存在内存
- **按需加载**: 只加载已下载视频的标签

## 故障排除

### 问题 1: 打标一直处于 processing 状态

**原因**:
- 后端服务崩溃
- Gemini API 超时
- 网络连接问题

**解决**:
```bash
# 查看后端日志
tail -f backend.log

# 重启后端服务
pkill -f "node.*server.js"
cd backend && node src/server.js
```

### 问题 2: 进度条不更新

**原因**:
- 前端轮询未启动
- API 返回数据格式错误

**解决**:
```javascript
// 检查浏览器控制台
// 应该每2秒看到 API 请求

// 刷新页面
window.location.reload()
```

### 问题 3: 标签结果为空

**原因**:
- 视频内容无法识别
- 标签分类未初始化
- Gemini API 返回格式错误

**解决**:
```bash
# 初始化标签数据
cd backend
node src/scripts/initTags.js

# 查看 Gemini 响应日志
grep "Gemini Analysis Response" backend.log
```
