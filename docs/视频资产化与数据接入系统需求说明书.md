# **模块需求文档：项目创建与视频资产化 (Ingestion & Asset Acquisition)**

## **1. 业务流程图 (User Workflow)**

1.  **上传 (Upload):** 用户拖拽 Excel/CSV 文件 -> 前端解析表头。
2.  **映射 (Map):** 用户指定哪一列是视频 URL (必选)，哪几列是业务指标 (消费/ROI 等)。
3.  **创建 (Create):** 后端初始化项目 ID，启动异步下载任务。
4.  **展示 (Display):** 用户进入项目详情页 -> 看到视频列表正在逐个点亮（下载完成可播放）-> 看到报告页显示“AI 分析排队中”。

---

## **2. 详细功能需求与 UI/UX 规范**

### **2.1 新建项目向导 (New Project Wizard)**

此模块是一个全屏模态框 (Modal) 或独立页面，引导用户完成数据清洗。

#### **步骤 1: 文件上传 (File Dropzone)**
*   **UI 布局:**
    *   居中放置一个大尺寸的上传区域 (`w-2/3 h-64`)。
    *   样式: `bg-slate-50 border-2 border-dashed border-slate-300 rounded-xl hover:border-indigo-500 transition-colors`。
    *   文案: "Click to upload or drag Excel/CSV containing Video URLs"。
*   **交互细节:**
    *   文件校验: 仅接受 `.xlsx`, `.csv`。限制大小 50MB。
    *   上传成功后: 显示文件名、行数（e.g., "Found 102 rows"），并自动跳转至步骤 2。

#### **步骤 2: 字段映射 (Column Mapping) [关键]**
*   **逻辑:** 前端读取 Excel 表头 (Header Row)，要求用户将其映射到系统标准字段。
*   **UI 布局:** 左右分栏。
    *   **左侧:** "Your File Columns" (读取到的表头)。
    *   **右侧:** "System Fields" (下拉菜单)。
*   **必填映射项:**
    *   `Video URL` (必须精准映射，否则无法下载)。
    *   `Video ID` (可选，若无则系统自动生成)。
*   **指标映射项 (动态添加):**
    *   用户需勾选需要分析的指标列，例如将 "消耗" 映射为 `Consumption`，将 "点击量" 映射为 `Click Volume`。
*   **底部操作栏:**
    *   按钮: `生成项目` (Primary, Indigo)。点击后调用 API 创建项目。

---

### **2.2 后端视频下载引擎 (Video Downloader Service)**

这是一个后台静默运行的服务，不涉及前端界面，但前端需要轮询其状态。

*   **逻辑:**
    1.  接收前端传来的 URL 列表。
    2.  利用 `Video ID` 作为文件名，将视频下载至本地存储 (e.g., `./storage/projects/{project_id}/videos/{video_id}.mp4`)。
    3.  **异常处理:** 若下载失败 (链接失效/权限限制)，将该视频状态标记为 `Error`，并在数据库记录错误原因。
*   **技术点:** 使用 `Radis Queue` 队列处理下载任务，避免阻塞主线程。

---

### **2.3 项目详情页：视频列表视图 (Video Assets Tab)**

这是用户在等待 AI 分析时的主要交互界面。

*   **布局:** 侧边栏导航，主内容区为网格布局。
*   **UI 构成:**
    *   **顶部工具栏:**
        *   左侧: "Total Videos: 102" | "Downloaded: 45" | "Failed: 2".
        *   右侧: 搜索框、筛选器 (All / Downloaded / Pending)。
    *   **内容区 (Grid View):** 采用 `grid-cols-4` (四列卡片布局)。

*   **视频卡片状态设计 (Video Card States):**

    *   **状态 A: 下载中 (Pending/Downloading)**
        *   **样式:** `bg-slate-100` 灰色卡片。
        *   **内容:** 中心显示 `animate-spin` (加载转圈图标) 或 进度条。
        *   **交互:** 不可点击播放。显示文案 "Downloading..."。

    *   **状态 B: 下载完成 (Ready)**
        *   **样式:** 显示视频首帧缩略图 (Thumbnail)。
        *   **内容:**
            *   底部显示 Video ID。
            *   右上角显示绿色小圆点 `bg-emerald-500` (表示文件本地就绪)。
        *   **交互:** 鼠标悬停 (Hover) 时，显示 "Play" 按钮覆盖层 (`bg-black/50`)。点击触发**视频播放模态框**。

    *   **状态 C: 下载失败 (Error)**
        *   **样式:** `bg-rose-50 border border-rose-200`。
        *   **内容:** 红色警告图标 + "Download Failed"。
        *   **交互:** Hover 显示错误原因 (e.g., "404 Not Found")。

*   **播放模态框 (Playback Modal):**
    *   点击卡片后弹出。使用 HTML5 `<video>` 标签播放本地 MP4 文件。
    *   右侧预留空白区域，标题为 "AI Analysis Tags"，当前显示 "Waiting for Analysis..." 占位符。

### **2.4 项目详情页：分析报告视图 (Report Dashboard - 待分析状态)**

由于 Gemini 打标和回归建模尚未完成，此页面不能显示空白图表，而应展示**“处理进度流”**。

*   **UI 布局:**
    *   **中心状态区 (Hero Section):**
        *   大图标: 一个动态的 AI 芯片或处理中的雷达图标。
        *   主标题: 根据项目状态显示。 刚开始的状态是“等待视频下载完成”。

        3.  **视频打标:** ⏳ Pending.

*   **交互细节:**
    *   当后端 `视频下载` 进度达到 100% 时， `视频打标` 进度条旁边显示一个发起视频打标的按钮。

## **3. API 接口规范 (Interface Specs)**

### **3.1 创建项目**
*   **Endpoint:** `POST /api/projects`
*   **Request:**
    ```json
    {
      "project_name": "Elixir V Cream Analysis",
      "column_mapping": {
        "url_col": "Video_Link",
        "id_col": "Video_ID",
        "metrics": {"roi": "ROI_Value", "click": "Click_Count"}
      },
      "raw_data": [ ...rows... ] // 或上传文件后返回的 file_id
    }
    ```
*   **Response:** `{ "project_id": "proj_123", "status": "created" }`

### **3.2 获取视频列表与状态**
*   **Endpoint:** `GET /api/projects/{project_id}/videos`
*   **Response:**
    ```json
    {
      "summary": { "total": 102, "downloaded": 45, "failed": 0 },
      "videos": [
        {
          "id": "vid_001",
          "status": "ready",
          "local_path": "/static/proj_123/vid_001.mp4",
          "url": "http://..."
        },
        {
          "id": "vid_002",
          "status": "downloading",
          "progress": 45
        }
      ]
    }
    ```
    *前端需每隔 5-10 秒轮询此接口，更新列表状态。*

### **3.3 获取项目整体状态**
*   **Endpoint:** `GET /api/projects/{project_id}/status`
*   **Response:**
    ```json
    {
      "current_step": "video_download", // 枚举值: ingestion, video_download, ai_tagging, modeling, completed
      "progress_percentage": 45,
      "estimated_time_remaining": "1h 30m"
    }
    ```
