# 项目创建与视频资产化模块使用指南

## 模块简介

本模块实现了从数据导入到视频下载的完整工作流，符合需求文档中"数据接入与视频资产化"的所有要求。

## 核心功能

### 1. 项目创建向导 (Project Wizard)
- ✅ 文件上传（Excel/CSV）
- ✅ 字段映射配置
- ✅ 视频URL和ID映射
- ✅ 业务指标映射
- ✅ 数据验证

### 2. 视频下载引擎
- ✅ 异步后台下载
- ✅ 并发控制（3个并发）
- ✅ 进度跟踪
- ✅ 错误处理和重试
- ✅ 自动文件存储

### 3. 项目详情页
- ✅ 视频列表网格展示
- ✅ 实时状态更新（5秒轮询）
- ✅ 视频播放功能
- ✅ 进度步骤条
- ✅ 统计信息展示

### 4. 项目管理
- ✅ 项目列表
- ✅ 项目状态跟踪
- ✅ 项目进度可视化

## 使用步骤

### 第一步：准备数据文件

准备一个包含视频URL和业务指标的 Excel 或 CSV 文件，例如：

| Video_ID | Video_URL | ROI | Click_Count | Consumption |
|----------|-----------|-----|-------------|-------------|
| vid_001 | https://... | 2.5 | 1000 | 500 |
| vid_002 | https://... | 3.2 | 1500 | 600 |

### 第二步：启动服务

确保前后端服务都已启动：

```bash
# 1. 更新数据库结构
cd backend
npm run update-db

# 2. 安装新依赖
npm install

# 3. 启动后端
npm run dev

# 4. 安装前端依赖（在项目根目录）
cd ..
npm install

# 5. 启动前端
npm run dev
```

### 第三步：创建项目

1. 访问 http://localhost:3000
2. 点击侧边栏"项目管理"
3. 点击"新建项目"按钮
4. 上传准备好的数据文件
5. 配置字段映射：
   - 选择视频URL列（必选）
   - 选择视频ID列（可选，不选则自动生成）
   - 添加业务指标映射
6. 点击"创建项目"

### 第四步：监控下载进度

创建项目后会自动跳转到项目详情页：

1. **进度步骤条**：显示当前处理阶段
2. **统计信息**：显示总视频数、已下载、下载中、失败数量
3. **视频卡片**：
   - 灰色 = 等待下载
   - 蓝色 + 进度条 = 下载中
   - 绿色 = 下载完成
   - 红色 = 下载失败

4. **实时更新**：页面每5秒自动刷新状态

### 第五步：播放视频

- 点击已下载的视频卡片（绿色）
- 弹出播放器模态框
- 可以直接播放本地视频

## API 接口

### 创建项目
```http
POST /api/projects
Content-Type: application/json

{
  "project_name": "项目名称",
  "column_mapping": {
    "url_col": "Video_URL",
    "id_col": "Video_ID",
    "metrics": {
      "roi": "ROI",
      "clicks": "Click_Count"
    }
  },
  "raw_data": [
    { "Video_URL": "...", "Video_ID": "...", "ROI": 2.5, "Click_Count": 1000 }
  ]
}
```

### 获取视频列表
```http
GET /api/projects/{project_id}/videos
```

### 获取项目状态
```http
GET /api/projects/{project_id}/status
```

## 数据库表结构

### videos（视频表）
- `id`: 视频ID
- `project_id`: 所属项目
- `video_url`: 原始URL
- `local_path`: 本地存储路径
- `status`: pending | downloading | ready | error
- `progress`: 下载进度 (0-100)
- `error_message`: 错误信息
- `file_size`: 文件大小
- `duration`: 视频时长

### video_metrics（视频指标表）
- `video_id`: 视频ID
- `project_id`: 所属项目
- `metric_name`: 指标名称（roi, clicks等）
- `metric_value`: 指标值

### video_tags（视频标签表，为AI打标预留）
- `video_id`: 视频ID
- `tag_category_id`: 标签分类
- `tag_name`: 标签名称
- `confidence`: 置信度

## 视频下载服务

### 下载队列管理
- 使用内存队列
- 支持3个并发下载
- 自动重试机制
- 失败记录错误信息

### 存储结构
```
storage/
└── project_{project_id}/
    └── videos/
        ├── vid_001.mp4
        ├── vid_002.mp4
        └── ...
```

### 下载流程
1. 用户创建项目 → 视频记录写入数据库（status: pending）
2. 后端自动将视频添加到下载队列
3. 下载服务处理队列：
   - 更新状态为 downloading
   - 下载视频文件
   - 更新进度
   - 完成后标记为 ready 或 error
4. 更新项目整体进度

## 项目状态流转

```
ingestion → video_download → ai_tagging → modeling → completed
   ↓              ↓               ↓            ↓          ↓
数据导入      视频下载        AI打标      归因建模     完成
```

## 常见问题

### Q: 视频下载失败怎么办？
A: 系统会自动标记失败的视频，并记录错误原因。可以在项目详情页查看失败原因。

### Q: 可以同时创建多个项目吗？
A: 可以，但下载队列是全局共享的，会按顺序处理。

### Q: 支持哪些视频格式？
A: 支持所有可通过HTTP下载的视频格式，默认保存为.mp4。

### Q: 视频存储在哪里？
A: 存储在 `backend/storage/project_{id}/videos/` 目录下。

### Q: 如何清理已下载的视频？
A: 删除项目时会自动删除相关视频文件（数据库级联删除）。

- **HTTP请求**: axios
- **文件系统**: fs-extra

## 性能优化建议

1. **大文件处理**：对于大型Excel文件，建议限制单次上传行数（<1000行）
2. **并发控制**：根据服务器性能调整并发下载数量
3. **存储清理**：定期清理长时间未使用的视频文件
4. **数据库索引**：已在video_id、project_id等字段创建索引

## 安全注意事项

1. 视频URL验证：确保URL来自可信源
2. 文件大小限制：防止存储空间耗尽
3. 下载超时设置：防止长时间挂起
4. 错误重试限制：避免无限重试
